# NEON//ECOLOGY｜霓虹生态箱

一个可长期迭代的赛博朋克城市生态模拟器原型。玩家不直接操纵每个居民，而是观察居民、势力、资源和社会关系在多轮模拟中的演化。

## 当前版本

- 10 名居民、3 个势力：新纪元科技、自由港社区、幽网。
- 城市资源：信用点、食物、能源、医疗物资。
- 城市指标：稳定度、环境污染、公众信任。
- 每天由程序执行资源消耗、居民行动、势力变化和事件更新。
- 居民有目标、性格、个人资源和近期记忆。
- 可推进一天、连续模拟、暂停、保存/读取本地快照、注入事件、重置世界。
- 无 API Key 时完全可以离线游玩。
- 配置 DeepSeek 后，模型只提出行动建议；行动必须经过服务端和前端白名单校验，最终状态由本地模拟引擎执行。

## 运行要求

Node.js 18 或更高版本。

```bash
npm install
npm start
```

浏览器打开 `http://localhost:3000`。

## 配置 DeepSeek（可选）

1. 复制 `.env.example` 并重命名为 `.env`。
2. 在 `.env` 中设置 `DEEPSEEK_API_KEY=你的密钥`。
3. 可按需修改 `DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`。
4. 重启服务。顶部状态会显示 AI 已连接。

密钥只保存在服务端 `.env`，不要将其写进 `public/app.js`，也不要提交 `.env` 到 Git。

如果不配置密钥，游戏会自动运行离线规则。若模型服务出错，本回合也会回退到离线规则。

## 设计原则

1. **程序拥有最终状态。** 模型只能提出有限类型的行动，不能直接修改资源、指标、存档或运行代码。
2. **离线优先。** 没有 API 时也能推进模拟。
3. **状态可保存。** 当前世界以带版本号的 JSON 保存到浏览器 `localStorage`。
4. **控制调用成本。** 每回合最多发送一组居民提案请求，最多选 3 名居民。
5. **渐进开发。** 后续可以将模拟引擎拆分为模块，加入关系网络图、历史曲线、更多居民和势力事件。

## 当前原型限制

- 视觉地图是 CSS 绘制的示意图，并非真实地图。
- 居民行动规则属于原型规则，尚未进行复杂的经济平衡。
- AI 模式会把选中的居民信息发给 DeepSeek；避免将真实个人信息放入模拟数据。
- `localStorage` 只保存在当前浏览器。清理浏览器数据可能导致存档丢失，重要进度请导出/备份（后续版本可加入 JSON 导入导出）。
